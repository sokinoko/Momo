## 새 채팅에서 가장 먼저 할 일

```

```

`index.html` 안에 아래가 전부 base64/인라인으로 들어 있어 복원이 됩니다.

| 복원되는 것 | 복원 안 되는 것 |
|---|---|
| `app.js` `views.js` `style.css` | `manifest_meta.json` (build.py가 참조) |
| `topics_all.json` `ox_items.json` `passages.json` | `tests/*.js` (4종) |
| 아이콘 4종 (192/512/180/32) | `src_2027_9/*.py` (데이터 입력 스크립트) |

`manifest_meta.json`은 `index.html`의 매니페스트 base64를 디코딩해 **icons 필드만 빼고** 다시 만들면 됩니다.
(icons가 원래 마지막 키라, build.py가 `meta['icons'] = ...`로 다시 붙여도 순서가 그대로여서 바이트가 일치합니다.)

**복원 검증**: `python3 build.py --out _rebuilt.html && cmp _orig.html _rebuilt.html` 이 통과해야 다음으로 넘어갑니다.

## 데이터 구조

### ox_items.json — 선지
```json
{
  "id": "ox-27m9-1", "no": 1,
  "text": "에피쿠로스는 참된 행복을 위해 모든 인간관계에서 벗어난 삶을 살아야 한다고 본다.",
  "answer": "X", "topics": ["epicureanism"],
  "source": "2027 9평", "set": "2027-9평",
  "fix":   "정치적 삶에서는 물러나되 벗과의 우정은 적극적으로 추구해야 한다고 본다.",
  "note":  "은둔은 공적·정치적 삶에서의 은둔이지 인간관계의 단절이 아니다.",
  "plain": "…",  "same": ["…"]
}
```

| 필드 | 상자 이름 | 조건 |
|---|---|---|
| `fix` | 이렇게 고치면 맞는 선지 | X 선지만 |
| `plain` | 쉬운 말로 | O 선지만 |
| `same` | 같은 말을 바꿔 쓴 선지 | O 선지만, 배열 |
| `note` | X면 「왜 틀렸나」 / O면 「함께 알아둘 것」 | 둘 다 |

출처 표기는 OX와 제시문이 다릅니다. **OX는 `2027 9평` / `2027 수특 p.111`**, **제시문은 `2026-11` / `2026-수특-20` / `2024-수완-112` / `출제 예상`**.

### topics_all.json — 필기
```json
{ "id":"confucius", "order":1, "unit":"유교", "title":"공자",
  "outline":[{"i":0,"t":"1. 시대: <r>B.C 5C</r>"}],
  "deep":[...], "table":{"cols":[...],"rows":[...]},
  "story":["공자는 세 살에 아버지를 잃었다. …"],
  "figures":[{"name":"트라시마코스","tag":"소피스트","gist":"…",
              "quote":"정의란 강자의 이익 외에…","qsrc":"플라톤 『국가』",
              "clue":["정의는 강자의 이익이다"]}] }
```

- `i` 는 들여쓰기 0~3
- `<r>` 빨강 · `<b>` 파랑 · `<span class='note'>` 회색 · story에서는 `<k>` 검정 강조
- **필기 표기**: `<o>동그라미</o>` `<s>그어 지움</s>` `<box>네모</box>` — 색을 물려받는다
- `figures` 는 주제 안에서 잠깐 나오는 사상가. `quote`를 쓰면 `qsrc`가 반드시 있어야 한다

### passages.json — 제시문
```json
{ "id":"ps-donghak-13", "text":"우리의 도는 무위이화(無爲而化)이다…",
  "topic":"modern-korean-ethics", "name":"동학", "by":"최제우",
  "aliases":["동학","최제우","해월"], "source":"2023-06",
  "clues":["우리의 도는 무위이화(無爲而化)이다"] }
```

- `by`는 정답 화면에 괄호로 붙는다 → `답: 동학 (최제우)`. 없으면 표시되지 않는다
- `clues`는 **본문에 그대로 들어 있는 구절**이어야 한다 (스크립트가 검사)
- 본문에 **줄바꿈은 쓰지 않는다.** 책에서 한 번호 안에 가운뎃점(·)으로 두 덩이가 묶여 있으면
  **같은 출처를 단 별개 제시문 두 편**으로 넣는다 (전체 758편에 `\n` 0건)
- 따옴표는 **곧은 따옴표** `'` `"` 를 쓴다 (‘ ’ 같은 굽은 따옴표는 데이터에 없다)

## 절대 어기면 안 되는 규칙

1. **정답은 타이핑된 「빠른 정답」 PDF에서만 읽는다.** 손글씨 채점본 금지. 블록 단위로 옮기고 개수를 재검산할 것.
2. **본문을 지어내지 않는다.** 사진이 잘리거나 손가락에 가리면 그 문항은 빼고 번호를 보고할 것.
   → 실제로 정약용 제시문 038쪽이 붉게 날아가 1~11번과 18번을 비워 두었다.
3. **id를 추측하지 않는다.** 반드시 실제 데이터를 먼저 읽고 확인할 것.
4. **중복 판정은 텍스트 + 출처 둘 다 같을 때만.** 본문만 같고 출처가 다르면 별개 기출.
5. **데이터는 json을 고치고 `build.py`를 다시 돌린다.** `index.html` 직접 수정 금지.
6. **필기는 나누지 않는다.** OX 전용 세부 주제는 `OX_TOPIC_EXTRA` / `OX_TOPIC_CHILDREN`로 처리.
7. **화면에 교재 이름(포스텝·심기일전)을 노출하지 않는다.** `set` 필드는 화면에 안 나오므로 괜찮다.
8. **해설을 정답에 끼워 맞추지 않는다.** 정답이 X니까 X인 이유를 억지로 만들어 내면,
   선지에 없는 말을 끼워 넣은 엉터리 해설이 남는다(해외 원조 `ox-w8-133` 사례). 근거가 안 잡히면 확인 요청으로 돌릴 것.

  - 유형 일곱 가지 (`MOCK_MIX`: right .28 / wrong .20 / box .16 / venn .06 / algo .06 / trio .06, 나머지 pair)
    - `right` 제시문 1편 + 「옳은 것은?」 — 정답 O선지 1 + 오답 X선지 4
    - `wrong` 제시문 1편 + 「옳지 않은 것은?」 — 정답 X선지 1 + 오답 O선지 4
    - `pair` 갑·을 제시문 2편. 자리 구성은 **갑2·을2·공통1 / 갑3·을2 / 갑2·을3** 중에서 고른다.

    - `algo` **알고리즘(순서도)** A ─예→ B ─예→ 갑 / A ─아니요→ C ─예→ 을

      「…라는 질문에 긍정의 대답을 할 것이다」류는 이중 질문이 되므로 제외한다.
      선택지 생성은 `box`·`venn` 과 같은 `mockOptSet` 을 쓴다.
